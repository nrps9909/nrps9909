# ColorPicker #286: release the drag after touchcancel

On [ColorPicker #286](https://github.com/react-component/color-picker/pull/286) head `9ce50dcf3b7d3b3fd58d24e2c538107957c7ec4f`, the author adopted util's public hook and raised the minimum dependency. The package passes 69 tests, types, lint, compilation and formatting. The same head also makes document touchmove non-passive, which fixes scrolling during a normal drag.

In Chrome/156.0.8078.80, Chrome DevTools Protocol touch input on an isolated real-hook fixture reproduces a remaining regression: start a drag, move, send touchCancel, then swipe on a separate part of the page. The current head prevents the outside swipe and emits five extra drag changes. The previous hook also leaks changes after cancel but does not prevent scrolling. The candidate frees the listener set on touchcancel without firing completion; it preserves the normal drag and allows scroll after end, cancel and unmount. See [raw comparison](chrome-results.json) and [candidate](candidate.patch). This is not a physical-device or screen-reader test.

To rerun, check out the stated head, check and apply the patch with git apply, then copy the patched src/hooks/useColorDrag.ts to a temporary path. Set CANDIDATE_SOURCE to that path, COLOR_PICKER_REPO to the ColorPicker checkout with dependencies, PUPPETEER_REPO to a checkout containing node_modules/puppeteer, and CHROME_EXECUTABLE to your Chrome binary. Run node probe.cjs; it reads both original revisions with git show and writes chrome-rerun.json. Use a disposable checkout for applying the patch. Source provenance is the existing upstream PR; its [MIT notice](LICENSE-upstream) is included. This candidate has not been adopted upstream. AI-assisted implementation and validation.
